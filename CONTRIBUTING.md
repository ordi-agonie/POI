# Contribution

## Méthode de travail

Avant de modifier un fichier existant :
- vérifier sa version actuelle ;
- demander le fichier si son état actuel n'est pas disponible.

Lorsqu'un problème concret est identifié :
- le corriger immédiatement s'il est local et sans risque ;
- sinon créer explicitement une tâche dans `Plan.md`.

Lorsqu'une décision modifie le modèle, l'architecture ou le comportement :
- mettre à jour la documentation concernée avant le commit.

Avant un commit :
- tester le comportement concerné ;
- vérifier que la documentation est cohérente avec le code.
