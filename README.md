# POI

**Point Of Interest**

Application personnelle permettant de capturer, organiser, retrouver et redécouvrir des citations, concepts et idées afin de pouvoir les réutiliser au moment opportun dans une discussion, un écrit ou une réflexion.

## Objectif

Retrouver facilement une formulation, une idée ou une perspective pertinente au moment où elle peut être utile.

L'application doit progressivement devenir un outil personnel de récupération d'idées, et pas seulement une bibliothèque de citations.

## Principes

- L'ajout d'un POI doit être rapide.
- Le contenu du POI est la seule information obligatoire.
- Les autres informations peuvent être ajoutées ou complétées plus tard.
- Un POI peut être enrichi progressivement.
- Les informations dont la structure n'est pas encore stabilisée peuvent être conservées dans les notes.
- Les données appartiennent à l'utilisateur et restent exportables.
- L'application doit rester simple et répondre à des besoins réels.
- Le modèle doit évoluer à partir des usages réels plutôt que de fonctionnalités hypothétiques.

## Version actuelle

La version actuelle permet de :

- ajouter un POI ;
- modifier un POI ;
- supprimer un POI ;
- lister les POI ;
- conserver les POI localement sur l'appareil ;
- marquer un POI comme favori ;
- conserver une raison de conservation ;
- gérer le statut d'un POI ;
- conserver des informations de provenance.

Le modèle reste en cours de construction et pourra être ajusté à partir de l'utilisation réelle.

## Hors périmètre actuel

Les fonctionnalités suivantes ne font pas partie de la version actuelle :

- tags personnels ;
- groupes personnels ;
- relations entre POI ;
- recherche sémantique ;
- suggestions automatiques de thèmes ;
- analyse automatique du contenu par IA ;
- graphe d'idées ;
- synchronisation entre appareils ;
- comptes utilisateurs ;
- OCR ;
- audio ;
- bibliographie structurée avancée ;
- localisation précise dans une source ;
- gestion avancée des personnes et de leurs rôles.

Ces fonctionnalités pourront être réévaluées si un besoin réel apparaît.

## Données

Les données sont actuellement stockées localement dans le navigateur.

Le projet vise à conserver des données exportables et indépendantes de l'interface afin de permettre une évolution ultérieure du stockage sans perdre les informations de l'utilisateur.
