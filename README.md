# POI

**Point Of Interest**

Application personnelle permettant de capturer, organiser, retrouver et redécouvrir des citations, concepts et idées afin de pouvoir les réutiliser au moment opportun dans une discussion, un écrit ou une réflexion.

## Objectif

Retrouver facilement une formulation, une idée ou une perspective pertinente au moment où elle peut être utile.

L'application doit progressivement devenir un outil personnel de récupération d'idées, et pas seulement une bibliothèque de citations.

## Principes

- L'ajout d'un POI doit être rapide.
- Le contenu du POI est la seule information obligatoire.
- Les autres informations peuvent être ajoutées ou complétées plus tard.
- Un POI peut être contextualisé progressivement.
- Les données appartiennent à l'utilisateur et restent exportables.
- L'application doit rester simple et répondre à des besoins réels.

## Version actuelle

La première version permet de :

- ajouter un POI ;
- modifier un POI ;
- supprimer un POI ;
- lister les POI ;
- rechercher des POI ;
- marquer un POI comme favori ;
- gérer les POI à classer ;
- associer des tags personnels aux POI ;
- regrouper des POI dans des groupes personnels ;
- afficher un POI de manière aléatoire ;
- exporter et importer les données au format JSON.

## Hors périmètre actuel

Les fonctionnalités suivantes ne font pas partie de la première version :

- IA ;
- recherche sémantique ;
- synchronisation entre appareils ;
- comptes utilisateurs ;
- OCR ;
- audio ;
- graphe de connaissances ;
- relations entre POI ;
- notes personnelles développées ;
- analyse automatique avancée du contenu.

Ces fonctionnalités pourront être réévaluées si un besoin réel apparaît.
