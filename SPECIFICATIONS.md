# Specification

## Vision

POI est une application personnelle permettant de capturer, organiser, retrouver et redécouvrir des citations, concepts et idées afin de pouvoir les réutiliser au moment opportun.

## Utilisateur

POI est destiné à un usage personnel.

## Capture

- Ajouter un POI.
- Le contenu est la seule information obligatoire.
- Les informations complémentaires peuvent être renseignées ultérieurement.
- La capture initiale doit prendre moins de 10 secondes.

## Gestion

- Lister les POI.
- Modifier un POI.
- Supprimer un POI.
- Marquer un POI comme favori.
- Identifier les POI à classer.

## Organisation

- Gérer les thèmes.
- Exploiter les mots-clés.
- Conserver les informations de provenance lorsqu'elles sont disponibles.

## Recherche

- Recherche plein texte.
- Recherche par auteur.
- Recherche par source.
- Recherche par thème.
- Recherche par mots-clés.

## Découverte

- Afficher un POI aléatoire.
- Accéder aux favoris.

## Données

- Stockage local initial.
- Export JSON.
- Import JSON.

## Types de contenu

Un POI peut notamment être :

- une phrase ;
- plusieurs phrases ;
- un extrait d'article ;
- un passage de livre ;
- une retranscription de podcast ;
- une retranscription de vidéo ;
- une idée ou formulation personnelle.

La longueur du contenu n'est pas limitée par le modèle conceptuel.

## Provenance

Lorsqu'elle est disponible, la provenance d'un POI peut comprendre :

- auteur ;
- source ;
- type de source ;
- date de publication ou de diffusion ;
- URL.

Les informations de provenance sont facultatives.
